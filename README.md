# 指律 (FingerFree) — 每日 10 分钟吉他左手独立性训练 iOS 应用

专为打破**中指与无名指肌肉联动**设计的原生 SwiftUI iOS 应用（兼容 iOS 18 – iOS 27），内置高精度合成音频节拍器、四阶段动态指板/手势可视化引导、一键 `-10 BPM` 紧绷降速与每周 `+5 BPM` 提速评估，并已配置 GitHub Actions 自动打包无签名 IPA。

## 每日 10 分钟训练流程

| 阶段 | 时间 | 练习项目 | 节拍器建议 (4/4拍) | App 内置可视化引导 |
|---|---|---|---|---|
| 1. 神经唤醒 | 2 分钟 | 无琴桌面独立敲击 | 60 BPM (一拍一下) | 桌面四指动态模型：食指与小指锁定贴桌，中指/无名指随拍交替单抬 1–2 cm |
| 2. 基础定型 | 3 分钟 | 低把位保留指爬格子 | 60–70 BPM (一拍一音) | 5–8 品交互指板：从 6 弦 5 品开始 1-2-3-4 爬格子，高亮当前移动指与「保留指」 |
| 3. 专项剥离 | 3 分钟 | 中指/无名指跨弦交替 | 50–60 BPM (一拍一音) | 食指 3 弦 5 品 + 小指 3 弦 8 品锁定，四拍动态指引 `4弦6品 → 2弦7品 → 2弦6品 → 4弦7品` |
| 4. 实战应用 | 2 分钟 | C - Am - F - G 慢速转换 | 60 BPM (四拍换一次) | 实时和弦指法图（支持大横按 / 小横按 F 切换），重点高亮中指与无名指落位 |

## 核心功能亮点

- **零外部依赖高精度节拍器**：基于 `AVAudioEngine` 实时合成木鱼清脆节拍音（第 1 拍重音），支持触觉震动节拍与静音切换。
- **一键「手指紧绷 -10 BPM」按钮**：训练页常驻红色醒目降速按钮，发现紧绷或联动时单手一键降速并自动记住新速度。
- **每周提速自检（+5 BPM 标准）**：训练结束弹出打卡与自检表单（连续 2 分钟零失误 + 手背前臂无酸胀），达标后可一键将各阶段目标速度 `+5 BPM`。
- **一毫米原则与黄金时段提醒**：训练全程防息屏，内置动作规范速查与历史打卡天数统计。

## 下载并安装到 iPhone

1. 打开 [GitHub Releases](https://github.com/xxm-666/FingerFree-iOS/releases/latest)，在 **Assets** 下下载 `FingerFree-v<版本号>-unsigned.ipa`（例如 `FingerFree-v2.5.1-unsigned.ipa`）。直接下载 `.ipa` 即可，无需解压，也不用下载 `Source code (zip)`。
2. 下载的是未签名 IPA，请用 **AltStore**、**SideStore** 或 **Sideloadly** 签名并安装。已安装 **TrollStore（巨魔）** 的兼容设备也可用它安装。

### GitHub Actions 构建产物

如果要测试某次提交，请在 **Actions** 中打开对应的成功构建，从 **Artifacts** 下载 `FingerFree-v<版本号>-unsigned-ipa`，解压后取出其中的 `.ipa`。推送到 `main` 或 `feat/*` 分支、推送 `v*` 标签，或手动运行工作流，均可触发构建。

本项目使用 [XcodeGen](https://github.com/yonaskolb/XcodeGen) 根据 `project.yml` 生成 Xcode 工程，无需提交 `.xcodeproj`。
